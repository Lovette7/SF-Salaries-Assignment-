# SF Salaries — Employee Profile System

A Jupyter Notebook + R submission that processes the San Francisco city
employee salary dataset, looks up individual employees, and exports one
employee's profile to a zipped CSV — which is then unzipped and displayed
using R.

## Contents

```
SF_Salaries_Assignment.ipynb   Main Jupyter Notebook (Python) — Tasks 1–5
salaries.csv                   Provided salary dataset (2011–2018, ~148,654 records)
unzip_and_display.R            R script — Task 6
Employee Profile.zip           Sample output already generated by the notebook
Employee Profile/              Unzipped copy of the sample output (for convenience)
README.md                      This file
```

## What Each Task Does

| # | Task | Where |
|---|------|-------|
| 1 | Import the provided salary data | `load_salary_data()` — reads `salaries.csv`, coerces pay columns to numeric, wrapped in error handling for missing/empty/misencoded files |
| 2 | Process the salary data using a dictionary | `build_employee_dictionary()` — converts the DataFrame into `{ "EMPLOYEE NAME": [ {year record}, ... ] }` |
| 3 | Create an employee lookup function | `get_employee_details(name)` — returns an employee's record(s) by name |
| 4 | Error handling | A custom `EmployeeNotFoundError` exception, plus type/value checks, are demonstrated against bad input (wrong type, blank name, unknown employee) |
| 5 | Export employee details to CSV, zipped into "Employee Profile" | `export_employee_profile(name)` — writes a CSV into an `Employee Profile/` folder, then zips that folder into `Employee Profile.zip` |
| 6 | Unzip and display with R | `unzip_and_display.R` — unzips `Employee Profile.zip` and prints the CSV contents using base R |

## How to Run

### Python Notebook (Tasks 1–5)

Requires Python 3 with `pandas` and `numpy` installed, plus Jupyter.

```bash
pip install pandas numpy jupyter
jupyter notebook SF_Salaries_Assignment.ipynb
```

Run all cells top to bottom. The notebook:
1. Loads `salaries.csv`
2. Builds the employee dictionary
3. Demonstrates `get_employee_details()` on both valid and invalid input
4. Exports **NATHANIEL FORD**'s profile as an example, producing
   `Employee Profile/NATHANIEL_FORD_profile.csv` and `Employee Profile.zip`

To generate a profile for a **different employee**, change the name passed
into `export_employee_profile("NATHANIEL FORD")` in the last code cell to
any name found in the dataset (names are matched case-insensitively).

### R Script (Task 6)

Requires R 4.x (base R only — no extra packages needed). Run it from the
same folder as `Employee Profile.zip` (i.e., after running the notebook,
or using the sample zip already included):

```bash
Rscript unzip_and_display.R
```

This unzips `Employee Profile.zip` into an `Employee Profile/` folder (if
not already present) and prints the contents of every CSV file inside it
to the console.

## Error Handling Highlights

- **Missing/empty/misencoded data file** — caught during import with a
  clear message instead of a raw traceback.
- **Unknown employee name** — raises a custom `EmployeeNotFoundError`
  that's caught and reported without stopping the notebook.
- **Bad input type** (e.g. passing a number instead of a string as a name)
  — raises `TypeError` before any lookup is attempted.
- **Blank name** — raises `ValueError`.
- **File/zip creation failures** (permissions, disk issues) — caught in
  `export_employee_profile()`, which prints a message and returns `None`
  rather than crashing.
- **R script** — checks that the zip file exists before attempting to
  unzip it, and that the CSVs inside are readable, printing friendly
  messages for either failure instead of halting on an R error.
